# Embedded CV viewer

Mozilla PDF.js 6.3.289, legacy distribution (Apache 2.0; see LICENSE).
Source: https://github.com/mozilla/pdf.js/releases/tag/v6.3.289

The distribution is self-hosted so viewing the CV requires no third-party service
or native PDF browser plugin. Source maps and the example PDF are omitted.
The only change to viewer.html is the site-viewer.css stylesheet link.

Replace assets/cv.pdf to update the CV; no image generation is required.
